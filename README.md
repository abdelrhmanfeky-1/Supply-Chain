# 📊 Supply Chain Analytics Dashboard

## 📌 Overview

An interactive **Power BI Supply Chain Analytics Dashboard** designed to analyze and monitor key supply chain performance indicators across suppliers, locations, products, shipping methods, and inspection results.

The dashboard transforms supply chain data into actionable business insights by analyzing **revenue, costs, profit margin, quantity sold, shipping time, defect rates, supplier performance, and transportation modes**.

---

## 🎯 Business Objectives

* Monitor overall supply chain performance
* Analyze revenue and cost across different locations
* Evaluate supplier performance
* Track product sales and profitability
* Analyze shipping time by transportation mode
* Monitor product inspection and defect results
* Identify high-performing locations and suppliers
* Support data-driven supply chain decisions

### Example Data Preparation

```python
import pandas as pd
import numpy as np

# Load dataset
df = pd.read_excel("Supply_Chain_Data.xlsx")

# Display basic information
print(df.info())

# Check missing values
print(df.isnull().sum())

# Check duplicated rows
print("Duplicates:", df.duplicated().sum())

# Remove duplicates
df = df.drop_duplicates()

# Remove unnecessary spaces from text columns
text_columns = df.select_dtypes(include="object").columns

for col in text_columns:
    df[col] = df[col].astype(str).str.strip()

# Convert numeric columns
numeric_columns = [
    "Revenue",
    "Cost",
    "Quantity Sold",
    "Price",
    "Defect Rate"
]

for col in numeric_columns:
    if col in df.columns:
        df[col] = pd.to_numeric(df[col], errors="coerce")

# Check cleaned dataset
print(df.info())
print(df.head())
```

### Exploratory Data Analysis

```python
# Descriptive statistics
print(df.describe())

# Revenue by location
revenue_by_location = (
    df.groupby("Location")["Revenue"]
      .sum()
      .sort_values(ascending=False)
)

print(revenue_by_location)

# Revenue by supplier
revenue_by_supplier = (
    df.groupby("Supplier Name")["Revenue"]
      .sum()
      .sort_values(ascending=False)
)

print(revenue_by_supplier)
```

### Visualization

```python
import matplotlib.pyplot as plt

revenue_by_location.plot(
    kind="bar",
    figsize=(10, 6)
)

plt.title("Revenue by Location")
plt.xlabel("Location")
plt.ylabel("Revenue")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```
